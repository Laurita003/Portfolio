# Persönliches Web-Portfolio (Laurita.dev)

Ein responsives Web-Portfolio zur Präsentation meiner Software-, KI- und Web-Projekte sowie meines akademischen Werdegangs an der RPTU Kaiserslautern-Landau.

Live Demo: https://laurita003.github.io/Portfolio/

## So funktioniert's

* Durchstöbere die Übersicht meiner bisherigen Software- und Studienprojekte.
* Nutze den dynamischen Projektfilter, um gezielt nach Technologien oder Themen zu suchen.
* Wechsle jederzeit zwischen dem hellen und dunklen Farbmodus (Day/Night-Mode).
* Schaue dir Live-Demos und Quellcodes über die hinterlegten Links direkt an.
* Nutze das integrierte Kontaktformular, um mir direkt eine Nachricht zu senden.

## Features

* Responsives UI/UX-Design für Desktop und mobile Endgeräte
* Dynamischer Day- und Night-Mode
* Interaktiver Projektfilter
* Funktionales Kontaktformular (Web3Forms)
* Übersichtlicher Aufbau zu Studium, Skills und Projekten

## Verwendete Technologien

* HTML5
* CSS3
* JavaScript
* Web3Forms

## Über das Projekt

Laurita.dev ist ein persönliches Webprojekt von Laurita Elsa Kenfack, mit dem ich meine Arbeiten aus dem Informatikstudium an der RPTU sowie eigene Entwicklungsprojekte gebündelt präsentiere. Ziel war es, eine moderne, übersichtliche und interaktive Plattform für Bewerbungen und den fachlichen Austausch zu schaffen.

## Lokal starten

1. Repository herunterladen oder klonen:
   `git clone https://github.com/Laurita003/Portfolio.git`
2. Den Projektordner in Visual Studio Code öffnen.
3. `index.html` im Browser öffnen.
Alternativ kann das Portfolio direkt über GitHub Pages aufgerufen werden.
